## Why It Fits the Brief

### Delightful

Smol Town turns a local small model into a cast of seven distinct villagers. They
wake into a brewing scandal, gossip, feud, confess, and react to one another while
the user watches the drama unfold. God-mode event injection lets the user stir the
town directly and immediately see how its residents respond.

### AI Is Load-Bearing

The town is the AI. There is no scripted dialogue: every beat is generated by a
villager agent from its persona, private secret, relationships, and recent town
memory. Remove the model and there is no conversation, story, or drama.

### Original Concept

Instead of presenting one assistant, Smol Town makes a whole community from small
agents. A mention-aware speaker loop encourages exchanges to chain naturally, so
the result behaves like an unscripted soap opera rather than a sequence of isolated
model responses.

### Polished Gradio App

The Gradio Space presents the seven-person cast, an evolving town feed, portrait
avatars, a live relationship graph, one-click chaos events, user-controlled god-mode
events, and downloadable structured agent traces. It opens directly on the town's
central scandal so the core experience is immediately visible.

## Models & Data

- **Qwen/Qwen3-4B:** powers the seven villager agents in-Space on ZeroGPU.
- **black-forest-labs/FLUX.2-klein-4B:** generated the character portraits offline.

Each generated beat also produces a structured trace containing `tick`, `speaker`,
`role`, `model`, `context`, `system`, `output`, and `ts`. The current town session
can be exported as JSONL from the app.

## How It Works

- **Seven agents:** every villager combines a persona, a private secret, and
  relationships with the rest of the cast.
- **Emergent turn-taking:** a tick loop chooses the next speaker, biased toward a
  villager mentioned in the previous line, which helps dialogue chain into drama.
- **Rolling memory:** each agent receives a recent window of town feed lines as its
  immediate context.
- **God mode:** the user can inject an event into the shared feed and let the agents
  react.
- **Structured observability:** every generated beat is recorded as an exportable
  JSONL agent trace.
- **Offline execution:** villager inference runs locally inside the Hugging Face
  Space on ZeroGPU, without external APIs.

```bash
cd smol-town
pip install -r requirements.txt
python app.py
```
